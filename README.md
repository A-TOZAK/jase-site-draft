- 検索サイトには出ない設定にしています。

## 気になる所の伝え方

1. スマホかパソコンで、見るページを開きます。
2. 一番上の帯にある「気になる所をメモ」を押します。ページが A、B、C…の区画に分かれて見えます。
3. 気になる所を押して、一言書きます。何か所でも書けます。ほかのページに移っても、メモはまとめて残ります。
4. 「まとめてコピー」を押して、Claude Code、LINE、メールのどれかに貼ります。

メモは、開いたブラウザの中にだけ残ります。ほかの人には見えません。

学会の方に見てもらうときも、同じ手順です。コピーした文を、そのまま送ってもらってください。

## 下書きだけの印

- 区画の記号は、ページの上から順に A、B、C…とつきます。コピーした文には、ページの名前と区画の名前も入ります。
- 「確認中」「調整中」「準備中」の印は、まだ決まっていない所や、学会に確かめる所です。
- 「下書きのメモ」と書いた灰色の箱は、学会に確かめたいことです。本番では消します。
- まだ作っていないページと、外のサイト（会員の仕組み、YouTube など）にはつないでいません。押すと、一言だけ出ます。
- お問い合わせのフォームは、送っても何も届きません。
- 動画は、学会のYouTubeチャンネルへ本当につないでいます。

## 版の進め方

いただいたメモをまとめて直したら、版を1つ上げます。v4 の次は v5 です。

何を直したかは、[CHANGELOG.md](CHANGELOG.md) に書きます。前の版には、git のタグで戻せます。

## ここに置かないもの

打ち合わせの記録、見積もり、学会の内部資料、ほかのサイトの画面写真、人のお名前と個人の連絡先は置きません。ここに置くのは、サイトの部品だけです。
