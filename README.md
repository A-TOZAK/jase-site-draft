# 日本外科教育学会サイト　デザイン案

日本外科教育学会のホームページを作り直すための、デザイン案（下書き）です。公式サイトではありません。

- 見るページ：https://a-tozak.github.io/jase-site-draft/
- 今の版：v1（2026年11月3日）。トップページだけです。
- 日付、費用、名前は今のサイトから写したもので、学会の確認前です。
- 検索サイトには出ない設定にしています。

## 気になる所の伝え方

1. スマホかパソコンで、見るページを開きます。
2. 一番上の帯にある「気になる所をメモ」を押します。ページが A から I の区画に分かれて見えます。
3. 気になる所を押して、一言書きます。何か所でも書けます。
4. 「まとめてコピー」を押して、Claude Code、LINE、メールのどれかに貼ります。

メモは、開いたブラウザの中にだけ残ります。ほかの人には見えません。

学会の方に見てもらうときも、同じ手順です。コピーした文を、そのまま送ってもらってください。

## 版の進め方

いただいたメモをまとめて直したら、版を1つ上げます。v1 の次は v2 です。

何を直したかは、[CHANGELOG.md](CHANGELOG.md) に書きます。前の版には、git のタグで戻せます。

## ここに置かないもの

打ち合わせの記録、見積もり、学会の内部資料、ほかのサイトの画面写真は置きません。ここに置くのは、サイトの部品だけです。
